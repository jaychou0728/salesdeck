# XBuddy 开发对话记录（模板）

> **重要说明**
> 本文件只是记录模板，仓库中**没有**预置任何与 XBuddy 的对话内容。
> 作业要求 AI 工具使用过程可追溯，因此**必须粘贴真实发生的 XBuddy 对话记录**（原文或截图），并说明对 AI 生成代码做了哪些校验、修正与兜底。
> **禁止虚构、改写或补写未发生的对话。** 没有记录的部分请如实留空或标注“未使用/无记录”。

## 记录规范

1. 按时间顺序记录，每次一个条目；保留真实时间戳。
2. 对话内容尽量原文粘贴；截图放在 `docs/assets/xbuddy/` 下并在此引用。
3. 每段 AI 产出都要有对应的验证证据：命令、测试结果、报错与修复、人工 review 结论。
4. 涉及密钥、客户敏感信息的片段必须打码。
5. 只记录与项目开发相关的对话，不混入无关闲聊。


## AI 生成代码的校验与兜底清单

演示/提交前逐项确认并在此打勾：

- [ ] 每个 AI 生成的模块都能对应到真实需求或测试用例。
- [ ] 关键路径（工具校验、权限、幂等、确认令牌、事务、库存锁）经过人工逐行 review。
- [ ] 所有测试通过：`pnpm test`、`pnpm test:e2e`、`pnpm build`、`pnpm eval`。
- [ ] 评测报告 `docs/EVAL_REPORT.md` 由脚本真实生成，未手改数字。
- [ ] 发现 AI 代码问题时，记录原始问题、修复方式与回归测试。
- [ ] 不依赖 AI 生成内容的“看起来正确”，以命令输出与测试结果为准。
- [ ] 无密钥、无真实客户数据进入仓库或截图。
